# Visual Direction and Composition

## When to use

Use when a new surface has no visual direction, an interface feels generic, the hierarchy is unclear, or multiple structures are plausible.

## Inputs

- user, task, frequency, stakes, and environment;
- realistic content, strongest supported answer, primary action, caveats, and secondary paths;
- neighboring product screens, brand assets, design tokens, and component primitives;
- viewport constraints, content volume, localization, and delivery framework.

## Direction procedure

1. **Frame the job.** Write privately: “For `<user>` trying to `<job>`, this surface should make `<answer/action>` obvious while preserving `<constraint>`.”
2. **Name the posture.** Choose a precise character such as quiet technical, dense operational, editorial evidence-led, warm utilitarian, playful tactile, or severe institutional. Avoid mood words that do not change implementation.
3. **Translate posture into decisions.** Name the typography, density, grid, contrast, shape, imagery, and interaction choices that carry it.
4. **Identify the memory.** Decide the one relationship or behavior someone should remember. It must help the task: a comparison geometry, exceptionally fast workflow, strong typographic moment, useful diagram, or distinctive navigation model.
5. **Reject the obvious template.** Name the default layout this category invites. Keep it only when the material genuinely earns it.
6. **Compare structures.** When two structures are credible, sketch both before coding. Change topology, sequence, density, and evidence placement rather than palette.
7. **Commit.** Choose one direction and execute it consistently. Do not average incompatible concepts into a neutral compromise.

## Composition rules

- The first viewport is the argument. It should expose identity, the user's question, the strongest answer or action, and decisive evidence without ceremonial setup.
- Build a page-level throughline. Each major section answers a new question and changes the reader's understanding.
- Give each reading moment one focal relationship. Supporting elements should be quieter and fewer.
- Map relationships to geometry before components: comparison to aligned columns, sequence to ordered flow, magnitude to common scale, hierarchy to proportion, dependency to connection.
- Compose a field, not a vertical stack of unrelated modules. Align objects to shared edges, baselines, grid lines, or a deliberate optical center.
- Use repetition only for true peers. Unequal findings should receive unequal space or order.
- Pace the scroll with intentional changes in density while retaining one visual grammar.
- End on the resolved action, implication, decision, or honest open question. Sources and metadata follow quietly.

## First-read tests

- **Squint:** blur or defocus the page. The dominant object and reading path should remain obvious.
- **Text mask:** hide the words. Scale, grouping, alignment, and progression should still express hierarchy.
- **Five-second recall:** the remembered item should be the decision, evidence, or tool—not merely a big title.
- **Transplant:** if the same composition could serve an unrelated product unchanged, strengthen the subject-specific move.

## Anti-template rules

- Replace a centered generic hero with a claim, comparison, working tool, or task-specific composition.
- Replace uniform card grids with hierarchy, aligned evidence, groups, or a continuous layout.
- Replace decorative metric tiles with a composed relationship or table when values need comparison.
- Replace arbitrary asymmetry with asymmetry that expresses importance, sequence, or interaction.
- Replace unsupported visual drama with clearer content selection, proportion, pacing, or evidence placement.
- Keep blank areas honest; do not fill thin evidence with decoration.

## Exploration mode

Build three variants by default and no more than five. Give each a named structural axis, the same realistic content, the same functionality, and the same viewport. Keep the picker neutral and switching instant. A direction is meaningfully different only when it changes navigation, hierarchy, sequence, density, composition, or interaction.

## Completion

The direction sentence predicts the implementation, the first viewport communicates the primary job, every section advances a distinct question, one subject-specific organizing move exists, and the structure survives realistic content at narrow and wide widths.

## Escalate

Escalate when the intended audience, core decision, brand ownership, or primary action is genuinely ambiguous and choosing incorrectly would alter product or commercial meaning.
